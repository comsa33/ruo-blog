# ruo-blog

Engineering notes at [blog.po24lio.com](https://blog.po24lio.com) — the companion
to [po24lio.com](https://po24lio.com).

Posts are MDX files under `content/posts/`, written to be read alongside
interactive diagrams rather than as plain prose. The component kit that draws
those diagrams lives in `src/components/diagram/`.

```bash
npm install
npm run dev        # http://localhost:4111
```

Agents working in this repo: read [AGENTS.md](AGENTS.md) first.
